# 💼 Task Wallet

Task Wallet adalah sebuah web application sederhana yang digunakan untuk mengelola task dan mencatat aktivitas/pekerjaan secara digital. Project ini dibangun sebagai bagian dari latihan pengembangan web modern dengan fokus pada UI yang clean, ringan, dan responsif.

---

## 🚀 Demo

👉 Live Website:  
https://task-wallet.pages.dev/

---

## 📌 Fitur Utama

- 📋 Manajemen daftar task (todo/pekerjaan)
- ➕ Tambah task baru dengan cepat
- ❌ Hapus task yang sudah selesai atau tidak diperlukan
- 💾 Penyimpanan data (local state / browser storage jika digunakan)
- 📱 Tampilan responsif (mobile & desktop friendly)
- ⚡ UI ringan dan cepat

---

## 🧠 Tujuan Project

Project ini dibuat untuk:

- Melatih pemahaman dasar web development
- Mempelajari state management sederhana
- Membuat UI/UX yang bersih dan user-friendly
- Latihan deploy web ke platform hosting (Cloudflare Pages / static hosting)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla / Framework jika digunakan)
- Cloudflare Pages (deployment)
